# Matriz de revisión de la consigna

|---|---|
| Selenium + JUnit + Cucumber | `pom.xml` + `TestRunner.java` |
| POM | `src/main/java/com/upb/pages` |
| Al menos 5 scenarios | `saucedemo.feature` |
| Hooks | `Hooks.java` con `@Before` y `@After` |
| Scenario Outline | Escenario de ordenamiento por precio |
| Background | `Antecedentes` con acceso y login |
| DataTables | Productos múltiples y checkout |
| Assertions | Step Definitions con JUnit Assertions |
| Extent HTML | `test-output/ExtentReport/ExtentReport.html` |
| Spark HTML | `test-output/SparkReport/Spark.html` |
| Extent PDF | `test-output/PdfReport/ExtentPdf.pdf` |
| Evidencia en fallos | Screenshot en `@After` |
